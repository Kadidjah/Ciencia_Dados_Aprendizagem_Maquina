# Introduction to Machine Learning

<br />

Welcome to Introduction to Machine Learning. This course introduces
**machine learning** (**ML**) concepts. This course does not cover how to
implement ML or work with data.

> [!NOTE]
> **Estimated Course Length:** 20 minutes

> [!NOTE]
> **Learning objectives:**
>
> - Understand the different types of machine learning.
> - Understand the key concepts of supervised machine learning.
> - Learn how solving problems with ML is different from traditional approaches.
